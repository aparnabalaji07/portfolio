# Aparna Balaji - Portfolio

My personal portfolio site, built with Next.js, Tailwind CSS, and Framer Motion.

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- Framer Motion

## Structure

- `src/components` — page sections (Hero, About, Projects, Experience, Contact) and shared UI
- `src/data` — content for projects and experience, kept separate from layout
- `src/app/projects/[slug]` — dynamic project detail pages
